# 🛒 Análise de Pedidos da Olist

Este projeto de Data Science utiliza dados reais de uma plataforma de e-commerce brasileira, com o objetivo de gerar insights sobre o comportamento de pedidos e logística. O estudo faz parte da construção do meu portfólio na área de Ciência de Dados.

## 📂 Sobre o Dataset

O dataset foi retirado do Kaggle:  
https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

Contém informações de mais de 100 mil pedidos, incluindo:
- Data de compra e entrega
- Status do pedido
- Informações de pagamento, clientes e logística

## 🎯 Objetivos da Análise

- Analisar a distribuição dos status dos pedidos (entregue, cancelado, etc.)
- Calcular o tempo médio de entrega dos pedidos
- Criar visualizações gráficas com Seaborn e Matplotlib
- Gerar estatísticas descritivas úteis para o negócio

## 📊 Principais Resultados

- 📦 Total de pedidos analisados: **99.441**
- ✅ Pedidos entregues com sucesso: **96.478**  
- ❌ Pedidos cancelados: **625**
- ⏱️ Tempo médio de entrega: **12.48 dias**
- 🧭 75% dos pedidos foram entregues em até **16 dias**
